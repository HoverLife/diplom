# Оформление результатов для диплома: визуализация и технические расчёты

Этот файл — готовый «каркас» того, как профессионально подать результаты модели
для презентации и текста диплома.

## 1) Логика повествования (рекомендуемая структура)

1. **Постановка задачи**
   - Цель: прогноз суммарной активной мощности `total_kw` на горизонте `t+h`.
   - Почему это важно: планирование нагрузки, снижение штрафов/перегрузок.
2. **Данные и предобработка**
   - Источник, период, шаг дискретизации (30 минут), число строк/признаков.
   - Очистка, обработка пропусков, выделение `kw`-каналов.
3. **Формирование признаков**
   - Временные признаки, лаги, rolling-статистики, целевая переменная.
4. **Модели**
   - `LinearRegression` как интерпретируемый baseline.
   - `RandomForestRegressor` как нелинейная модель сравнения.
5. **Оценка качества**
   - `TimeSeriesSplit` + финальный holdout.
   - Метрики MAE, RMSE, MAPE.
6. **Интерпретация и выводы**
   - Важные признаки, типичные ошибки, где модель работает хуже/лучше.
7. **Практический эффект**
   - Потенциальное применение в контуре управления нагрузкой.

## 3) Как подать технические расчёты (формулы для диплома)

### 3.1 Целевая переменная

\[
\text{total\_kw}(t)=\sum_{i=1}^{m} kw_i(t)
\]

где \(m\) — число точек измерения.

Для горизонта прогноза \(h\):

\[
y_t=\text{total\_kw}(t+h)
\]

### 3.2 Признаки

- Лаги:
\[
 x^{(lag,k)}_t = \text{total\_kw}(t-k)
\]
- Скользящее среднее по прошлому окну \(w\):
\[
 x^{(mean,w)}_t = \frac{1}{w}\sum_{j=1}^{w}\text{total\_kw}(t-j)
\]
- Циклическое кодирование часа:
\[
 x^{(hour\_sin)}_t = \sin\left(2\pi\frac{hour_t}{24}\right),\quad
 x^{(hour\_cos)}_t = \cos\left(2\pi\frac{hour_t}{24}\right)
\]

### 3.3 Модели

- **LinearRegression**:
\[
\hat y_t = \beta_0 + \sum_{j=1}^{p}\beta_j x_{t,j}
\]
- **RandomForestRegressor**:
\[
\hat y_t = \frac{1}{B}\sum_{b=1}^{B} T_b(x_t)
\]
где \(T_b\) — предсказание отдельного дерева, \(B\) — число деревьев.

### 3.4 Метрики

\[
\text{MAE}=\frac{1}{N}\sum_{t=1}^{N}|y_t-\hat y_t|
\]
\[
\text{RMSE}=\sqrt{\frac{1}{N}\sum_{t=1}^{N}(y_t-\hat y_t)^2}
\]
\[
\text{MAPE}=\frac{100\%}{N}\sum_{t=1}^{N}\left|\frac{y_t-\hat y_t}{y_t}\right|
\]

## 4) Шаблон текста для раздела «Результаты»

> Для оценки качества прогнозирования использовалась двухэтапная схема: (1) перекрёстная проверка `TimeSeriesSplit` на обучающем сегменте временного ряда и (2) финальная проверка на отложенной тестовой части (последние 20% наблюдений). Такая постановка исключает утечку информации из будущего и соответствует прикладному сценарию эксплуатации модели в энергетике.
>
> По результатам сравнения моделей `LinearRegression` и `RandomForestRegressor` лучшая модель выбиралась по минимальному значению MAE как наиболее интерпретируемой метрики ошибки в физических единицах (kW). Дополнительно анализировались RMSE и MAPE.
>
> Анализ распределения ошибок и их зависимости от времени суток показал, что наибольшие отклонения возникают в периоды резкого изменения нагрузки, что указывает на необходимость использования дополнительных технологических признаков (производственный календарь, события пусков/остановов оборудования) в дальнейших итерациях.

## 6) Советы по профессиональной подаче

- Все метрики подписывать в единицах измерения (kW, %).
- На графике факт/прогноз обязательно выделять тестовый интервал.
- Для честности указывать ограничение: модель обучена на исторических данных без внешних факторов.
- Добавить 1 слайд «Планы развития»: экзогенные признаки, ансамбли, адаптивное дообучение.
